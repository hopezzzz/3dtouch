# 安装

Touch 设备需要装两个东西，都来自 3D Systems，**不随本仓库分发**
（SDK 的授权禁止再分发，两个安装包也都超过 GitHub 的 100 MB 单文件上限）。

| | 必装 | 作用 |
|---|---|---|
| **Touch 设备驱动** | 是 | USB 驱动 + 运行时库 + 6 个官方上位机 |
| **OpenHaptics SDK** | 看情况 | 头文件、`.lib`、源码、40 个演示程序 |

**只用 Python 读数据的话，SDK 可以不装** —— `code/touchpy` 只需要驱动。

## 两种方式，选一个

### 自动 —— 双击 `一键安装.bat`

下载（约 280 MB）→ SHA-256 + 签名校验 → 依次运行两个安装程序。
SDK 的安装路径会预填成项目目录下的 `OpenHaptics\`。

```cmd
一键安装.bat                            :: 下载 + 安装
一键安装.bat --download-only            :: 只下载，安装包自己去点
一键安装.bat --sdk-dir C:\OpenHaptics   :: SDK 装别处
一键安装.bat --all                      :: 加 Unity 插件、诊断工具、文档
一键安装.bat --docs                     :: 只下文档
一键安装.bat --list                     :: 只看清单
一键安装.bat --check                    :: 校验已下载的文件
```

需要 Python 在 PATH 上。

### 手动 —— 看 [`手动安装.md`](手动安装.md)

所有官方直链、安装步骤、路径建议、SHA-256 校验值，外加一节故障排查。
不想跑脚本、或者脚本下载失败时用这个。

## 文件

| | |
|---|---|
| `一键安装.bat` | 双击入口 |
| `fetch_vendor.py` | 下载 + 校验 + 调用安装程序的实现 |
| `手动安装.md` | 手动安装说明 |

下载的东西都会落到项目根目录的 `vendor/` 里（`installers/` 和 `docs/`），
这个目录不进版本库。
