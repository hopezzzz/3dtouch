# 手动安装

不想跑脚本就照这个来。全部链接都是 3D Systems 官方源，可以直接点开下载。

自动方式见同目录的 `一键安装.bat`（下载 + 校验 + 安装一条龙）。

---

## 第 1 步：接好硬件

1. **抓住设备两侧**从包装里取出 —— **不要抓笔杆或机械臂**，会损坏设备
2. **USB 线**接到设备和电脑
3. **电源适配器**两端接好 —— **这一步不能省**

> **只插 USB 不接电源，设备起不来。** 电源插上后，笔架凹槽（inkwell）上的
> 蓝色 LED 会快闪两下，那是设备自检通过的标志。

## 第 3 步：装驱动

运行 `Touch_Device_Driver_2025.12.12.exe`，一路 Next。

> **安装路径用它的默认值，别改。** 它要往 Windows 驱动库注册 USB 驱动
> （`touchusb.inf` / `gtouchusb.inf` / `touchxusb.inf`）。

**装完重启电脑。**

装好之后你会得到：

| | |
|---|---|
| USB 驱动 | 注册进 Windows，设备才能被识别 |
| 运行时库 | `hd.dll`、`hl.dll`、`PhantomIoLib42.dll` |
| 6 个官方上位机 | `Touch_Diagnostic_LegacyVersion.exe`、`Touch_SmartSetup.exe`、`Touch_Setup.exe`、`Phantom_Diagnostic.exe`、`TouchDemo.exe`、`AdvancedHIDTouchConfig.exe` |
| 一个 Unity 力反馈演示 | `OpenHaptics_Demos\HapticDemo\` |

**只想用 Python 读数据的话，装到这里就够了**，第 4 步可以跳过。

## 第 4 步：装 SDK

1. 解压 `OpenHaptics_Developer_Edition_v3.5.0.zip`，里面是一个 `.exe`
2. 运行它，组件全选（Program Files / GLUT / Start Menu Shortcuts）
3. **安装路径随便填**，装哪都行

推荐两种：

| 路径 | 好处 |
|---|---|
| `<本项目目录>\OpenHaptics` | 跟代码放一起，项目自包含 |
| `C:\OpenHaptics` | 多个项目共用 |

> **不要装进驱动的安装目录里面。** 那样卸载驱动时可能把 SDK 一起带走。

安装程序会自动设一个系统环境变量 `OH_SDK_BASE` 指向你选的路径，本项目的
代码靠它找 SDK，所以装哪都能找到。

装好之后：250 个头文件、46 个 `.lib`、160 份 C/C++ 源码、58 个 VS 工程、
40 个演示程序。

> **装完要新开一个终端**，之前就开着的窗口读不到新的 `OH_SDK_BASE`
> —— 进程只在启动时读一次环境变量。

## 第 5 步：验证 + 校准

新开一个终端，在项目目录下：

```cmd
python code\touchpy\check_device.py
```

三级都是绿的就说明链路通了：驱动 → USB 枚举 → HD API。

然后**把笔杆放进墨盒**（底座上的笔架凹槽），跑：

```cmd
python code\touchpy\calibrate.py
```

> 编码器是增量式的，每次设备**上电后都要校准一次**。
> 没校准之前坐标是偏的，力的方向也是错的。

搞定后：

```cmd
python code\touchpy\demo_read.py     :: 实时读数
Touch启动器.bat                      :: 玩厂家的 46 个程序
```

## 出问题了

### `check_device.py` 第 2 步报 USB 找不到设备

看有没有一个 **Code 43 / Device Descriptor Request Failed** 的设备（脚本会提示）。
VID/PID 全是 0 说明 Windows 连 USB 描述符都没读到 —— **这是线材、接口或供电问题，
不是驱动问题**，重装驱动没用。按顺序试：

1. 拔掉 USB 线
2. **拔掉电源适配器，等 10 秒，再插回去**（光拔 USB 不够，设备要彻底断电）
3. 插回电源，确认墨盒的蓝色 LED 快闪两下
4. USB 线插到**电脑机身上的接口**，不要走扩展坞或 HUB
5. 还不行就**换一根 USB 线** —— 这是最常见的原因

可以开着监视器边插边看：

```cmd
python code\touchpy\check_device.py --watch
```

### 报 `hdStartScheduler failed (0x0304)`，或读数永远不变

**设备被另一个程序占用了。** 一次只能有一个程序打开设备 ——
把正在跑的演示程序、Touch Diagnostic 或别的脚本关掉。

特别注意第二种表现：程序**看起来打开成功了**，但关节角永远是 0、
位置永远是 `(0, -110, -35)`。那是占位值，不是设备坏了。

### QuickHaptics 演示双击就闪退

用 `Touch启动器.bat` 启动，别直接双击 exe。那些程序缺三样东西：
DLL 不在自己目录里、需要 `OH_SDK_BASE`、必须从各自的 `bin` 目录启动。
启动器把这三件事都处理了。

### 校准状态一直是 `needs_update`

笔杆没放到位。放进墨盒后 `calibrate.py` 会自动检测并完成校准。
实在不行用驱动自带的 `Touch_SmartSetup.exe`，效果一样。
